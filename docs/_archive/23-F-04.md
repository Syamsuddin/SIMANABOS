# Arsip 23 — F-04 Anggaran tahunan (diterima 2026-10-22)

## F-04 Anggaran tahunan
- Given pagu diisi dengan `active_from_month=7`, Then laporan draf tercipta untuk Juli–Desember saja (idempoten saat dijalankan ulang).
- Given RKAS versi 2 berlaku 1 Juli, Then persentase Juni memakai versi 1 dan September memakai versi 2.
- Given anggaran > pagu + saldo awal, Then peringatan tampil tanpa memblokir simpan.
- Given saldo awal tahun pertama belum diverifikasi, Then laporan Januari tidak bisa dinyatakan selesai.
- Verifikasi: `php artisan test --filter=Budget` → hijau.
