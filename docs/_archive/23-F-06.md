## F-06 Dokumen PDF
- Given satu PDF ditandai BKU dan Rekap BMD, Then kelengkapan menghitung keduanya.
- Given berkas `.pdf` berisi PNG, When unggah, Then ditolak.
- Given ganti berkas, Then versi baru menjadi current dan versi lama tetap bisa diunduh pengguna berhak.
- Given hash sama sudah ada di laporan lain sekolah sama, Then peringatan tampil (tidak memblokir).
- Given laporan pernah diajukan, When hapus berkas, Then ditolak.
- Verifikasi: `php artisan test --filter=Document` → hijau.
- Sisa F-02 terpenuhi: `document_types` (seeder 9 kode), CRUD aturan `document_requirements` per tahun (tambah, hapus, salin dari tahun lalu; terkunci bila tahun ditutup) — `tests/Feature/Document/DocumentRequirementTest.php`.
